## What is Git?
Git is like a monitoring spirit that know all you are doing on your repository, infact if you deleted something and you dont know how to get it back, it helps you get it.

## What is GitHub?
GitHub is a website where codes are being stored expecially for easy collaboration

## What does git add do?
git add informs github that there is a new change that is about to be saved

## What does git commit do?
It is like clicking the save button and telling it what you want to save (desctiption)

## What does git push do?
It is to upload what you saved and your repository will not be uploaded if you did not push

## What does git pull do?
Git pull is used to download what is already on the repository
