# Lesson 1 Assignment

## What is Flutter?
Flutter is a cross functional UI platform created by google which enable us cross sectional application (both IOS and Android) using one code base.

## Why did Google create Flutter?
To save time and reduce developers stress

## What is Dart?
Dart is a programming language used in flutter to build apps.

## What is a Widget?
Widget is like each block in the structure of a building eg. Text, Column, row, column, scaffold, container etc

## What is the difference between a StatelessWidget and a StatefulWidget?
StatelessWidget are widget that are not movable while StatefulWidget are widget that are movable 

## What is Hot Reload, and why is it useful?
Hot Reload is an inbuilt flutter feature that helps reload apps once you save your project. It is useful for app update
