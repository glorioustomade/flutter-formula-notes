## What is a loop?
Loop repeat a block of code continuously, until it is false

## for
For loop is commonly used, it is used to repeat a block of code + 1 continuously , it is used when you know how many times you want to repeat

## while

it is usially used for password, when you know how many times you will repeat

## do while
This loop always runs at least once, even if the condition is false.

## for in
this combination of for and in, it is used with list

## break
it is used to stop a loop immediately

## continue
it is used to skip an iteration
