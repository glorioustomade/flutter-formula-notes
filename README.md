What problem does Flutter solve? Flutter saves time and helps companies create cross sectional app in one code base
Why does Flutter use Dart? Because dart supports hot reload, object oriented programming, just in time, async, strong typing and so on
What is a Widget? Widget is everything in flutter, it is like each block in building of an house e.g Text, button, column, appbar, padding, scaffold, row, etc.
What is the difference between StatelessWidget and StatefulWidget? StatelessWidget are immovable widget while stateful are movable 
Explain Hot Reload in your own words. This helps to load or rebuild your app afresh once you save your code.
